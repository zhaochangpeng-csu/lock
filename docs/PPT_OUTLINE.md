## 关键数字（讲解时统一口径）

- 融合阈值：**0.78**；权重：人脸 0.45 / 活体 0.25 / 声纹 0.20 / 红外 0.10
- 声纹阈值：**0.70**，最短有效语音 **2 秒**
- 一次性凭证有效期：**300 秒**，消费后立即失效
- 事件触发：陌生人 **3 秒**未识别自动写事件；离开 **5 秒**重新布防
- 内存实测：整机约 **5.5 GiB**（Orin NX 级，非 Nano 4GB）
