安全

四层约束

  • 融合层
    只有 Jetson 本地 FusionEngine 产出结果
  • 凭证层
    短时、一次性、过期与重复消费均拒绝
  • Agent 层
    只注册 current_auth_context 与 request_unlock
  • 执行层
    Bearer Token + SMART_LOCK_NO_UNLOCK 双重闸门
