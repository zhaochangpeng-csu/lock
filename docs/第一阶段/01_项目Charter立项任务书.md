## 1 执行摘要

本项目面向智能门锁方向，实际交付一个可运行的AI原型Demo。Demo基于NVIDIA Jetson Nano + 单个RGB摄像头 + 传感器 + 智能音箱实现，核心功能包括：单目深度估计（Depth Anything）、2D人脸识别、动作活体检测、声纹识别、人脸+声纹多模态融合、传感器触发唤醒、语音交互和模拟开锁输出。

创新点在于：不依赖昂贵的3D结构光/ToF硬件，仅用单目RGB相机配合开源深度估计模型，实现“深度辅助活体 + 3D人脸感知展示 + 多模态融合”的低成本端侧方案，同时全链路尽量使用InsightFace、MediaPipe、WeSpeaker等开源项目串联。

市场机会方面，中国智能门锁2025年全渠道零售额约212亿元，城镇家庭渗透率低于30%，中高端2500-3500元家用细分仍存在“全人群、端侧安全、开放生态”的差异化空间。由于本次为实习课程项目，3D结构光/ToF人脸、指纹、全自动锁体、安全芯片等量产模块以方案分析、软件模拟和公开资料验证为主，不作为真实硬件交付内容。

项目按IPD流程完成概念、需求、架构、详细设计、集成验证和Demo交付。研发周期示例为3-4个月，核心团队可按5-8人配置，预算以现有设备为主，额外耗材可控制在0-2000元。Demo阶段不追求量产商业回报，商业论证仅用于IPD学习。

**PDT建议：同意立项，启动CDCP流程，进入IPD概念阶段，按“实习Demo”范围完成TR1-TR6相应交付物。**

## 2 项目背景与公司战略匹配说明

### 2.1 立项背景

智能门锁行业正在从“功能竞争”转向“安全与体验竞争”。GB/T 44602-2024已于2025年4月实施，GB 21556.2-2025将于2026年3月实施，生物识别防伪、网络安全和个人信息保护成为产品准入硬性要求。

当前市场产品在“多模态”上多为简单“或逻辑”，缺少自适应降级；老人、儿童、特殊指纹、暗光逆光、口罩帽子等真实场景体验仍有明显短板；部分品牌将生物特征上传云端，用户隐私顾虑上升。本项目通过智能门锁AI原型Demo，验证“单目3D深度估计+多模态身份识别+端侧推理+传感器联动”的核心技术链路，为后续产品化提供概念验证。

### 2.2 与公司产品线战略匹配

本项目在IPD学习中对应智能家居/智能安防产品线。实习Demo聚焦智能门锁核心身份认证链路，后续可扩展多模态认证、智能猫眼/门铃、AI主动安防和统一身份认证平台，具备课程展示和长期产品化参考价值。

## 3 市场机会简要概述

- **目标客户**：城市中产家庭、有老人/儿童的多代同堂家庭，以及高端社区物业、智能家居集成商、长租公寓/民宿等渠道客户。
- **核心痛点**：老人指纹浅、儿童指纹小、暗光/逆光人脸识别失败、照片/视频/面具攻击担忧、生物特征云端上传隐私焦虑、多模态“伪融合”导致复杂场景仍不好用。
- **竞品短板与差异化机会**：头部品牌生态强，但特殊人群适配、端侧隐私、自适应多模态仍有空白。本次实习Demo以“人脸+声纹多模态融合、端侧推理、传感器联动”作为技术验证重点，不直接进入量产市场竞争。

## 4 产品完整定义

### 4.1 产品名称与产品定位

**产品名称（示例）**：面向家庭全人群的智能门锁AI原型Demo。

**产品定位**：基于 Jetson Nano + 单个RGB摄像头 + 传感器 + 智能音箱，实现“单目3D深度估计 + 人脸识别 + 声纹识别 + 多模态融合 + 传感器联动”的智能门锁AI原型，用于课程演示和技术验证。

### 4.2 核心产品能力

| 能力模块 | Demo实现内容 |
|---|---|
| 3D深度感知 | 基于单目RGB + Depth Anything/MiDaS生成深度图，实现低成本“单目3D估计” |
| 人脸识别 | 基于单个RGB摄像头的2D人脸检测、人脸特征提取、身份比对（InsightFace/ArcFace） |
| 活体检测 | 基于RGB的动作活体：眨眼、摇头、张嘴，并结合深度图辅助区分照片与真人 |
| 声纹识别 | 通过智能音箱/麦克风采集语音，提取说话人特征，实现声纹身份确认 |
| 多模态融合 | 人脸识别 + 声纹识别融合决策；低置信度时触发语音二次确认 |
| 传感器联动 | 人体接近传感器触发摄像头和算法，模拟“人靠近才唤醒门锁” |
| 语音交互 | 智能音箱播报提示音/语音，用户说出动态口令，系统语音反馈开锁结果 |
| 模拟开锁 | 通过舵机/LED/继电器或智能音箱语音反馈，模拟“开锁/上锁”动作 |
| App/Web模拟 | 用笔记本运行本地Web服务，实现用户注册、开锁记录、远程授权模拟 |
| 量产模块映射 | 3D人脸、指纹、全自动锁体、安全芯片等以方案分析+软件模拟呈现 |

### 4.3 交付形态

- 可运行的智能门锁AI Demo原型（Jetson Nano + 单个RGB摄像头 + 传感器 + 智能音箱）
- 人脸识别、活体检测、声纹识别、多模态融合的算法模型与源码
- 本地Web/App模拟管理端
- Demo演示脚本、演示视频、操作说明
- IPD过程文档：市场机会分析报告、关键技术预研报告、Charter、PRS等

### 4.4 技术架构简述

```text
感知层：单目RGB摄像头、人体接近传感器、智能音箱麦克风
  ↓
AI/算法层：Depth Anything/MiDaS单目深度估计
           InsightFace/ArcFace人脸识别
           MediaPipe动作活体
           WeSpeaker/SpeechBrain声纹识别
           多模态规则融合
  ↓
控制层：Jetson Nano（GPIO控制舵机/LED/继电器）
  ↓
交互层：智能音箱语音提示/反馈、本地Web/App模拟管理端
  ↓
数据层：用户特征库、开锁日志、事件记录（本地存储）
```

### 4.5 创新点与实现难度平衡

- **创新点1：低成本单目3D感知**  
  不使用昂贵的3D结构光/ToF硬件，仅用单个RGB摄像头 + Depth Anything/MiDaS实现深度图生成，展示“单目3D估计 + 深度辅助活体”的智能门锁概念。

- **创新点2：全开源端侧多模态融合**  
  使用InsightFace、MediaPipe、WeSpeaker/SpeechBrain、ONNX Runtime/TensorRT等开源项目串联人脸、活体、声纹和传感器，形成可运行Demo，便于课程展示和代码审查。

- **创新点3：规则化多模态决策**  
  不追求复杂不可解释的AI融合，而是用“人脸置信度 + 深度图平面检测 + 声纹确认 + 传感器触发”的规则融合，平衡安全性和实现难度。

- **难度控制**：优先跑通单目深度估计 + 人脸识别 + 动作活体 + 声纹识别主流程；传感器联动、智能音箱交互、Web管理端作为增强功能，避免Demo开发失控。

## 6 关键技术可行性结论

根据《关键技术预研报告》：

- **Demo实际可验证**：单目深度估计（Depth Anything/MiDaS）、2D人脸识别、动作活体、声纹识别、人脸+声纹多模态融合、传感器联动、语音交互、模拟开锁；全链路基于InsightFace、MediaPipe、WeSpeaker/SpeechBrain等开源项目；
- **方案级/模拟验证**：3D人脸活体、指纹识别、全自动锁体、安全芯片、低功耗整机、新国标认证，均以公开资料和方案分析为主；
- 多模态认证采用“规则策略优先”的框架，适合在Jetson Nano上快速落地；
- 遮挡训练可作为V2.0方向，本次Demo仅做基础场景验证。

**遗留风险**：Jetson Nano推理性能、RGB活体安全性、声纹噪声鲁棒性、Demo演示稳定性。实习阶段可通过简化场景、本地模拟和演示脚本控制风险。
