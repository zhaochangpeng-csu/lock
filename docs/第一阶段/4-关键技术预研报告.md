# 关键技术预研报告

## 5\.技术方案选型与最终结论

综合第3章技术难点识别、第4章专项预研验证结果及第6章性能与稳定性评估，本章对各关键技术进行最终选型决策，并给出项目技术层面的总体结论。

### 5\.1 技术方案选型原则

本项目技术方案选型遵循以下五条原则：

原则一：安全为红线。 任何涉及未经授权开锁、合法用户被拒绝进入、生物信息泄露的技术方案，在风险未完全关闭前不得进入量产。安全指标不具备让步空间。

原则二：用户体验为基线。 3D人脸识别成功率、指纹识别成功率、整机开锁响应时间和电池续航是用户能够直接感知的核心体验指标。方案选型时以实际用户场景测试数据为准，不以器件规格书或供应商实验室数据作为主要决策依据。

原则三：端侧优先。 生物特征采集、特征提取、模板存储和身份比对原则上在本地完成。云端和App主要负责设备管理、权限配置和事件同步，不参与基础身份认证决策。

原则四：继承与扩展平衡。 V1\.0优先保障基础开锁链路的稳定可靠，不堆砌功能。同时技术架构需预留多模态融合、OTA升级和后续产品系列化扩展能力，避免因V1\.0架构短视导致后续型号重复开发。

原则五：供应链可获取。 技术方案选型必须同步评估模组供应商量产能力、交期稳定性和第二供应商备选方案。单一来源且产能不透明的方案不予采用。

#### 5\.2\.4 声纹识别方案选型

经第4\.4节专项预研验证，声纹识别在本项目V1\.0中的定位为人脸辅助开锁，即“人脸为主、声纹为辅”的组合认证方式。选型结论如下：

基于上述数据及“人脸为主、声纹为辅”的产品定位，声纹最终选型结论如下：

应用方式：人脸\+声纹组合开锁

声纹辅助开锁的核心安全逻辑为：人脸识别负责“确认门前是本人”，声纹负责“确认本人在场且主动表达开锁意图”。人脸活体检测已能有效拦截照片、视频攻击，声纹辅助进一步增加攻击者同时通过人脸活体和声纹比对的难度，构成组合安全屏障。即使声纹被录音回放绕过，人脸活体仍为独立安全防线。

声纹方案整体判定为Pass（人脸\+声纹组合辅助开锁），纳入V1\.0产品功能范围。

V1\.0不开通以下能力：

- 声纹作为独立单因子开锁；

- 声纹作为人脸失败后的替代开锁方式；

- 声纹用于高风险操作（如远程开锁授权、支付确认）。

### 5\.4 技术可行性最终结论

综合第3章技术难点识别、第4章专项预研验证、第5章方案选型及第6章性能与稳定性评估，对本项目技术可行性给出以下最终结论：

三、后续重点关注事项

技术预研阶段的风险已基本关闭或明确应对方案，进入产品开发阶段后，以下事项需要持续关注并在量产前完成验证：

- 人脸模组在整机环境（面板玻璃透过率、结构公差）下的性能衰减，需在EVT/DVT阶段复测确认；

- 全自动锁体10万次寿命在量产批次中的一致性，需建立每批次抽检机制；

- 整机续航在真实家庭多场景（楼道频繁触发、Wi\-Fi信号弱）下的实测验证，需在PVT阶段完成至少2周连续实际环境测试；

- OTA异常恢复机制在多种失败组合场景下的可靠性，需专项冗余测试；

- 多模态融合策略在大规模用户（200人级以上）中的触发率和误触发率统计，需在Beta测试阶段收集数据；

- 人脸\+声纹组合开锁在实际楼道噪声环境下的声纹误拒率，需确保不会因声纹频繁失败影响组合开锁功能的正常使用体验；

- 声纹动态挑战口令的人机交互流畅度验证，确保用户跟读体验自然、等待时间可接受。

四、技术结论

本项目技术方案可行，风险可控，建议按计划进入V1\.0产品开发阶段。声纹识别以“人脸\+声纹组合辅助开锁”定位纳入产品交付，人脸为主认证、声纹作为增强确认因子，既增加了产品卖点和安全层次，又通过组合认证机制有效控制了单一声纹技术不成熟带来的安全风险。
